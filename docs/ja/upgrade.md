# 旧版からの手動アップグレード

[← ドキュメント一覧](../README.md)

**v0.3.0 より前を使っている方向けです。** v0.3.0 以降は `.\PierrotKnowledge2 Update` で更新できます。

旧版にはアップデート機能そのものが入っていないため、**一度だけ手動で入れ替える
必要があります。** そのあとは自動になります。

---

## 先に結論

**あなたのノートは消えません。** ノート（バンドル）はアプリのフォルダの外にあり、
入れ替えるのはアプリのフォルダだけだからです。

ただし手動作業なので、**始める前にバンドルの場所を確認してください。** 万が一
アプリのフォルダの中にバンドルを作っていた場合、フォルダごと入れ替えると消えます。

---

## 手順 0: バンドルの場所を確認する（必須）

アプリを起動し、**ウィンドウ下部のステータスバー**に出ているパスを見てください。
または、次のファイルを開きます。

```
%APPDATA%\OKF Wiki\session.json
```

`bundlePath` がバンドルの場所です。既定では次のどれかです。

```
C:\Users\<あなた>\Documents\OKF Wiki
```

### ここで確認すること

そのパスが、**アプリのフォルダ（`Pierrot KnowledgeV2`）の中に無いこと。**

| バンドルの場所 | 判定 |
|---|---|
| `C:\Users\me\Documents\OKF Wiki` | ✅ 安全。そのまま進めます |
| `C:\Users\me\Desktop\Pierrot KnowledgeV2\my-notes` | ❌ **アプリの中です。** 先に外へ移動してください |

中にあった場合は、`Documents` などアプリの外へフォルダごと移動してから、
アプリで開き直してください。

---

## 手順 1: バンドルをバックアップする

手動作業なので、念のため取ります。バンドルのフォルダを丸ごとコピーするだけです。

```
Documents\OKF Wiki  →  Documents\OKF Wiki_backup_20260803
```

**これはノートそのものです。** アプリを消してもこのフォルダがあれば復元できます。

---

## 手順 2: 新しい版を入れる

2 通りあります。**A のほうが簡単です。**

### A. まるごと入れ替える（推奨・ビルド不要）

1. リリースページから **`Pierrot.KnowledgeV2.zip`**（約 285 MB）をダウンロード
2. 展開する
3. **いまのアプリのフォルダを別名にリネーム**します（削除しない）

   ```
   Pierrot KnowledgeV2  →  Pierrot KnowledgeV2_old
   ```

4. 展開した `Pierrot KnowledgeV2` を元の場所に置く
5. **`SETUP.bat` を実行**（後述の理由で必要です）

`node_modules` と `build` が入っているので、ビルドは不要です。

### B. ソースだけ入れ替える（約 0.6 MB）

1. リリースページから **`PierrotKnowledge2-0.3.0.zip`**（約 0.6 MB）をダウンロード
2. 展開する
3. 中の `src` `test` `docs` `templates` `scripts` `assets` と、
   `package.json` `tsconfig*.json` `vite.config.ts` `SETUP.bat` を、
   **いまのアプリのフォルダに上書きコピー**

   > `node_modules` と `build` は zip に入っていません。**消さないでください。**

4. コマンドプロンプトでアプリのフォルダを開き、次を実行

   ```
   bun install
   SETUP.bat
   ```

   > zip には `PierrotKnowledge2.bat` も入っています。これが次回以降の
   > アップデート用コマンドなので、一緒にコピーしてください。

---

## 手順 3: SETUP.bat を必ず実行する

**アプリ名が `OKF Wiki` から `PierrotKnowledge2` に変わりました。** さらに
0.5.0 で**ウィンドウ版そのものを廃止**したため、旧版のショートカットが指していた
実行ファイルはもう作られません。

`SETUP.bat` が画面のビルドと新しいショートカットの作成をまとめて行います。
新しいショートカットは **ブラウザで開く形（`ui` モード）** を起動します。

作成後、**デスクトップの古い「OKF Wiki」ショートカットは削除**してください。
新しいものは「PierrotKnowledge2」という名前です。

旧版から持ち越した `build\dev-win-x64\` が残っている場合、これは廃止した
ウィンドウ版のビルド出力（約 117 MB）です。**もう何も読まないので削除して
構いません。**

---

## 手順 4: 起動して確認する

新しいショートカットから起動し、次を確認してください。

| 確認 | 期待される結果 |
|---|---|
| 前回開いていたバンドル | **自動で開きます** |
| ノートの件数 | 以前と同じ |
| バンドル直下 | `MAP.md` `human.md` `Task.md` が増えています |

### 自動で移行されるもの

手を動かす必要はありません。

- **設定とセッション** — `%APPDATA%\OKF Wiki\` から自動で読み出します。
  古いフォルダは消しません（次回保存時に新しい場所へ移ります）
- **`MAP.md` `human.md` `Task.md`** — 以前 `wiki/` の中にあった場合、
  バンドル直下へ自動で移動します。中身はそのままです
- **`AGENTS.md` `skills/` `loops/`** — 旧レイアウトで置かれていた場合は
  `wiki/` の中へ自動で移動します

### 確認できたら

手順 1 のバックアップと、手順 2A でリネームした `Pierrot KnowledgeV2_old` を
削除して構いません。**問題が出たときの戻り先なので、数日は残しておくことを
勧めます。**

---

## 次回以降

v0.3.0 が入っていれば、以降は次のコマンドだけです。

アプリのフォルダで実行します（`.\` が必要です — PowerShell はカレント
ディレクトリのプログラムを既定では実行しません）。

```powershell
.\PierrotKnowledge2 Update           # 確認のみ。ダウンロードして検証し、判定を表示
.\PierrotKnowledge2 Update --apply   # 実際に適用する
```

- ダウンロードは **GitHub が計算した sha256 と照合**します
- **古い版へは戻しません**（バージョンが下がる更新は拒否されます）
- 旧ファイルは削除せず退避します。`.\PierrotKnowledge2 Update --rollback <退避先>` で戻せます
- **バンドルがアプリのフォルダ内にある場合は、更新自体を拒否します**

---

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| ショートカットが反応しない | `SETUP.bat` を実行し直してください（フォルダ名が変わっています） |
| 起動するがノートが無い | 「開く」でバンドルのフォルダを選び直してください |
| ビルドが失敗する | アプリのフォルダで `bun install` を実行してから `SETUP.bat` |
| 元に戻したい | `Pierrot KnowledgeV2_old` を元の名前に戻すだけです |

**ノートが見当たらない場合でも、まだ消えていません。** 手順 1 のバックアップと、
元のバンドルフォルダの両方が残っています。慌てて削除しないでください。
