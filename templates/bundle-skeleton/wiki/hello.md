# ようこそ

これは OKF v0.2 に準拠した最小の概念ドキュメントです。上の `---` で挟まれた
部分が YAML frontmatter で、**必須の項目は `type` ひとつだけ**です。

## 3 つの層

- `raw/` — 元資料を置く場所。**書き換えません**（アプリが拒否します）
- `wiki/` — 知識の正本。人間と AI が対等に読み書きします。このファイルもここ
- `.rag/` — 検索インデックス。アプリが自動生成するので、触る必要はありません

## リンクの書き方

関係は普通の Markdown リンクで表します: [索引](./index.md)

ウィキ記法も同じ概念 ID に解決されるので、`[[hello]]` と書けばバンドルの
どこからでもこのページを指せます。

まだ書いていないページへのリンクも書いて構いません。未解決のリンクは
**これから書くべき知識**として一覧に出ます。

## 次にすること

1. このページを自由に書き換えてください（自動保存されます）
2. `Ctrl+P` でノートを検索、`Ctrl+K` で全文検索
3. サイドバーを右クリックして新しいページを作成
4. 詳しい使い方は同梱の `AGENTS.md` と、リポジトリの `docs/ja/` を参照
